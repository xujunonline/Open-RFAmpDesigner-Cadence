# RFAmpDesigner 论文资料

本目录保存 Open-RFAmpDesigner-Cadence 使用的公开论文资料：

- `RFAmpDesigner.pdf`：论文原文；
- `RFAmpDesigner_中文翻译.md`：结合 PDF 和 arXiv 源码校正的中文翻译；
- `figures/`：从论文资料整理出的插图；
- `source/2605.10093-source.tar`：arXiv 源码包；
- `source/RFAmpDesigner_extracted_text.txt`：PDF 文本抽取结果。

这些文件用于核对论文结构、公式、表格和实验描述。它们不包含作者的 Cadence 工程、商业 PDK、OCEAN 脚本、lookup table、KB/EB、prompt 或最终设计参数，因此只能支持方法级、流程级和趋势级复现。
