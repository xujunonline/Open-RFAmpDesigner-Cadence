## 工作日志

1. 重放上轮低噪声方案，六项指标一致，50 GHz NF 为 5.67048 dB。沿用上轮的噪声贡献分析，优先调整输入管 M1 和共栅管 MCG 的分指几何、总宽度与比例。把单级测到的噪声两端口数据与后两级及匹配网络组合，筛选后用完整 Spectre 验收。
2. 保持首级偏置在原网格内，0.675 V 方案中心 NF 降至 4.9193 dB。按原项目判据已经通过，但在 55 GHz 达到 5.7148 dB。为满足全带噪声要求，再单列扩展偏置试验。
3. 降低首级噪声后，部分候选增益过高，或末级提前压缩。用 HB 内部节点的压缩行为指导级间匹配和各级偏置调整。一次 0.775 V 试验已实现全带 NF ≤5 dB，但 IP1dB 加密复测仅比下限高 0.0174 dB。最终全带方案把这项余量增至 0.4321 dB，并将全带最高增益约束在 23 dB 内。
4. 最终全带方案的 M1 实际宽度 54.4 µm，MCG 为 60.0 µm，两者指宽分别为 1.7、1.5 µm；三级栅偏置分别为 0.775、0.650、0.625 V。较高增益方案保留相同有源器件与偏置，带内最低增益提高到 22.8463 dB，同时峰值达到 25.2823 dB。两组均通过项目六项判据。
5. 全带方案从归档 JSON 再次发起完整网表、密集扫频与细步长 HB，所有汇总指标逐项一致。主复测日志有 48 条 HB 牛顿迭代警告，Spectre 将对应解判为收敛，最终为 0 错误。结论适用于标称 N65 原理图与已测频率网格；工艺角、温度变化、版图寄生和硅结果仍待验证。

## 本机重放

在原 Mac 仓库根目录，使用新输出目录执行。脚本沿用既有工具名，规格由参数 S3 选择。

```bash
cd /Users/jason/Documents/Open-RFAmpDesigner-Cadence
PYTHONPATH=src .venv/bin/python scripts/refine_s7.py dense --spec S3 --fine-hb \
  --source results/repro/s3_n65_20261124/selected.json \
  --out results/runs/s3_fullband_repeat_01
```

- 全带方案、原偏置方案、较高增益方案分别在 results/repro/s3_n65_20261124 下的 selected.json、original_bias.json 和 higher_gain.json。每份均含设计参数与完整曲线。
- 主复测原始网表、PSF、DC 和 HB 在 results/runs/repro_cadence_pdk/20261124T012348_6ada1a/sim00001。归档参数的独立重放在 results/runs/repro_cadence_pdk/20261124T012416_6e2a1c/sim00001。
- 本轮 142 次 Spectre 进程，包含完整电路 93 次、分级两端口提取 45 次、首级参数扫描 4 次。4 次扫描内部合计 1,280 个参数点。本轮项目设计 LLM 调用 0 次；接管累计 625 次 Spectre。逐次记录在 results/repro/s3_n65_20261124/ledger.json。
- 实验报告可引用“经定向续调与标称 N65 验证，S1–S8 每个案例均已有通过项目判据的方案”。S7 的通过证据使用了扩展偏置。这里统计的是优化后有通过记录的案例数，从零设计的首次通过率需单独实验。
