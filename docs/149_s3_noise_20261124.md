# S3 · N65 标称原理图复现 · 2026-11-24

S3 的频带为 45–55 GHz，中心噪声系数上限为 5 dB。沿用 seed0 的三级拓扑、原负载、无源 Q 和六项验收条件。按另外五项全通过的条件选择中心噪声最低的候选。

| 阶段 | 50 GHz NF（dB） | 记录 |
|---|---:|---|
| 复测上轮起点 | 6.864072 | s3_noise_20261124/trial01.json；纹波 3.2364 dB |
| 首级尺寸与输入、级间网络联合优化 | 6.040732 | s3_noise_20261124/trial08.json |
| 第二级工作点与匹配重调 | 6.001693 | s3_noise_stage2_20261124/trial08.json |
| 回到首级，在当前宽度扫描偏置并重调匹配 | 5.697063 | s3_noise_bias_20261124/trial08.json |
| 第三级工作点与匹配重调 | 5.682527 | s3_noise_stage3_20261124/trial08.json |
| 重建该设计，独立 Spectre 确认 | 5.682527 | s3_noise_confirm_20261124/trial01.json |

原始记录都位于 results/runs 下。JSON 中的 raw_run 和 sim 对应 repro_cadence_pdk 中的仿真目录。36 次基线或候选仿真加 1 次独立确认，核对 37 条原始记录均为 ok。项目设计 LLM 0 次。接管以来 Spectre 累计 104 次。

本轮用每轮实测与两端口预测的差值修正局部预测。在 11 个频点拟合增益和输入匹配，联合选择工作点与无源参数，最终交给原项目完整频率网格、噪声及 HB 压缩仿真验收。首轮缓存筛选曾包含 0.70 V 候选，超出可用网格上限 0.675 V，预测无可靠依据。检查了所有实际派发的设计，各级偏置均在原网格内。脚本已限制后续筛选取值。各阶段同时重调匹配，数值变化不能单独归因于某一器件。

最终带内最低增益 22.7612 dB（允许 17–23），纹波 2.8567 dB（≤3），最差 S11 −10.1909 dB（≤−10），中心 NF 5.6825 dB（≤5），IP1dB −17.4609 dBm（≥−20），电流 28.6872 mA（≤30.03）。中心 NFmin 为 5.6646 dB，是当前电路的中心最小噪声系数。与实际 NF 相差约 0.018 dB。独立复测六项数值一致。优化起点电流为 23.3770 mA；新增电流消耗约 5.31 mA。尚未实现 S3 全项通过。

在仓库根目录复现选中的完整设计，输出目录须为新目录。

```bash
PYTHONPATH=src .venv/bin/python scripts/refine_s3_noise.py \
  --source results/runs/s3_noise_stage3_20261124/trial08.json --replay-only \
  --out results/runs/s3_noise_confirm_repeat
```
