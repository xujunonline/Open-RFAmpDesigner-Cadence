# 阶段 08 局部进展：论文式 (3) 的低保真 MCR 计算

来源为仓库内英文论文 `references/paper/RFAmpDesigner.pdf` 第 6 页及其 `references/paper/source/2605.10093-source.tar` 中的 `main.tex`。`src/orfadc/tools/mcr_model.py` 按 TeX 所列对称 MCR 公式计算复数 `Y11(s)`、`Z21(s)`、`I11(s)` 和 `V(s)=I11(s)Z21(s)/2`，在每个正频率点取 `s=j2πf`。输入明确分开 `ω0` (rad/s)、测量频率 (Hz)、`k`、`Q0`、`RS`、`R2`、`CS`、`gm` 与参考电阻，输出只称为**归一化理论电压响应**，不是 Spectre S21 或经过校准的级联增益。

英文 TeX 将 `C_L` 写为 `Im(Y11)/s`。在 `s=jω` 的数值计算中，直接除以复数 `s` 得不到实数电容；本实现按并联 RC 导纳 `Y=1/R+jωC` 使用 `C_L=Im(Y11)/ω`，并单独记录 `R_L=1/Re(Y11)`。这是本项目的物理量换算约定，**不是声称论文原式已勘误**。若 `R_L<=0` 或 `C_L<0`，响应仍可供数学审查，但 `passive_parallel_rc=false`，不得把该点当作可实现的正值 R/C 元件组合。

例如仅作离线自检的 `k=0.4, Q0=3, f0=f=10 GHz, RS=50 Ω, R2=200 Ω, CS=20 fF, gm=10 mS`，公式给出 `R_L=-700 Ω`、`C_L≈-295.57 fF`，因此**不能**从这一点生成被动 Spectre 网表或认定稳定/可制造。该例不是论文设计参数、PDK 仿真或 LNA 指标。`k=0` 的数学对照给出 `Z21=0`、`V=0`；`gm` 翻倍时理论电流/电压响应翻倍。测试还覆盖非有限输入、频率与耦合边界。

本阶段仍缺：与论文 Fig. 4 拓扑一致的无源 Spectre 网表、单级/级联模型误差校准、经授权工艺验证的物理 L/C/R/k 映射、实际 Q/自谐振约束、Stage 3 SA 优化与 Fig. 7-like 实测。下面只有本项目自定义的理想元件映射。不得用式 (3) 的纯计算曲线充当 Cadence 数据；非被动等效点必须从候选空间排除或转入更完整的复阻抗网络模型。

## 本项目的对称并联 RLC 映射

`src/orfadc/tools/mcr_lumped.py` 新增**本项目选择**的 Fig. 4 风格双节点被动模型：各节点并联正值 R/C 与线圈，线圈通过 `M=kL` 相互耦合。按无耦合并联谐振器的定义，`L=1/(ω0²C)`、`R=Q0/(ω0 C)`；以 1 A 归一化 Norton 电流激励输入节点，解 2×2 复数节点导纳矩阵，输出输入导纳和跨节点转移阻抗。`k=0` 时在 `f0` 的输入虚部为 0、输出转移为 0；参数和互感一致性由模型对象校验。

例如 `f0=30 GHz, Q0=3, C=100 fF, k=0.4` 的数学映射给出 `L≈281 pH`、`R≈159 Ω`、`M≈113 pH`。这些数值不来自 PDK，也不表示该线圈/耦合器的 Q、自谐振、面积或版图寄生可实现。论文只说用二分搜索映射 MCR 参数到物理设计，没有公开作者所用的具体映射表；本模块**不能**冒充原实现。它与式 (3) 的等效负载近似还未完成一致参考平面校准，不应直接比较 `V(s)` 与这里的转移阻抗。

## 理想元件 Spectre 校准（2026-09-26）

`src/orfadc/experiments/run_mcr_calibration.py` 由上述**本项目选择**的参数生成固定拓扑的 Spectre AC 网表：两节点各并联 R/L/C，`mutual_inductor` 以 `M=kL` 耦合，1 A AC 电流源从地向输入节点注入；输出开路，故 `V(n1)=1/Yin`、`V(n2)=Z21`。输入参数仅是有界数值，未拼接任意 Spectre 语句；运行前检查宿主可用物理内存至少 2.66 GiB。每次使用独立忽略目录，保存网表、Spectre 日志、原始 PSFASCII、逐点 CSV、指标及 SHA-256 证据清单。运行命令：

```powershell
$env:PYTHONPATH='src'
py -m orfadc.experiments.run_mcr_calibration
py -m orfadc.experiments.run_mcr_calibration --coupling-k 0
```

最初归档 `results/runs/mcr_calibration/20260926T110637Z_a9f8da6d/` 中 Spectre 仿真返回 0，但解析拒绝：本机 `lin=41` 产生 42 点，且电流源方向与节点方程相反。修正为 40 个间隔、交换源端点后，`20260926T110725Z_f700ad68/` 得到 41 点。加入 `1e-6` 最大归一化误差门槛后，最终独立 run `20260926T110844Z_4507a93b/` 的两节点最大误差分别约 `6.42e-16`、`8.93e-16`，`calibration_pass=true`；从原始 `ac.ac` 独立重算与归档指标相同，清单哈希通过。零耦合对照 `20260926T110754Z_9ed1be53/` 的 `Z21=0`，在相同 41 点网格上通过。全部是本机 Spectre 25.1 的理想无源 AC 结果，`not_lna_result=true`、`spec_pass=null`。

这一接近机器精度的一致性首先是因为 Python 和 Spectre 实现了**同一个理想线性节点方程**，校验符号、极性、频率轴和数据管线。论文 Fig. 4 的被动图示也有两组并联 R/C 与耦合线圈，但它区分 `RS/CS` 与 `R2/C2`，并用有方向的源电流、`Y11/Z21` 与单点源/负载近似；当前强制两端 R/C 对称且用向节点注入的归一化电流。

进一步的**局部论文公式对照**：令论文式 (3) 中 `RS=R2=Q0/(ω0 C)`、`CS=C`，取 `L=1/(ω0²C)`、`M=kL`，`gm` 只作 `Z21` 计算中未使用的占位参数。新增的逐点 `paper_z21` 比较在 `results/runs/mcr_calibration/20260926T112449Z_ab6efab3/` 对 20–40 GHz、41 点给出最大绝对差约 `2.07e-13 Ω`、以最大 `|Z21|` 归一化约 `2.60e-15`；原始 `ac.ac`、CSV、网表和 Spectre 日志有哈希清单。这个结果证明**式 (3) 的 `Z21` 子表达式**在该理想对称映射、端口定义和开路输出条件下与 Spectre 一致，不证明论文完整频带规划、多级耦合或 3% 误差主张。

`Y11` 的原样印刷式与端口导纳确实不一致：同一映射在 30 GHz 时，Spectre 端口 `1/V(n1)≈0.01595+j0.001933 S`，论文式 (3) 原样计算 `Y11≈-0.0004488-j0.005834 S`。复核**英文 TeX 原件**发现分母末项是 `R_S ω0³ Q`，没有 `s`；前两项以及分子各项量纲对应四次频率，而该末项只对应三次频率。保留 `paper_equation_3` 对印刷原式的实现，不暗中更改论文公式。

对本项目的**对称理想双节点 RLC**，令 `D=(1−k²)Q s²+(1−k²)ω0 s+Qω0²`，节点导纳矩阵消元给出 `Yin=N/(R_S ω0 s D)`，其中 `N` 恰是论文式 (3) 的四次分子。展开分母后与印刷式唯一可见差别是末项变为 `R_S ω0³ Q s`。`y11_dimensional_candidate` 仅把这个额外 `s` 当作待验证的量纲修正**假设**。只读 `audit_mcr_y11` 对旧 run `results/runs/mcr_calibration/20260926T112449Z_ab6efab3/` 的 41 点原始 Spectre `ac.ac` 逐点核对，先验证网表与 1 A 激励、频率网格和哈希清单，再以最大 `|Yin|` 归一化：印刷 `Y11` 最大误差 `2.181`，候选式最大误差 `2.52e-15`；候选绝对最大误差约 `4.36e-17 S`。零/非零耦合和多频离线测试也与该节点方程一致。复核命令：

```powershell
$env:PYTHONPATH='src'
py -m orfadc.experiments.audit_mcr_y11 results/runs/mcr_calibration/20260926T112449Z_ab6efab3
```

这**不等于**论文正式勘误：不能排除作者还使用了未公开的归一化/端口约定，且 Spectre 与候选式都描述本项目选择的同一个理想拓扑。原式计算的负等效 R/C 不能据候选式静默“修正”成论文结果；`I11`、`V(s)` 与级联有源电路仍未校准。阶段 08 后续须核对 Fig. 4 源/负载参考平面和线圈极性，加入工艺 Q/自谐振/寄生约束，完成 Stage 3 gain/ripple 仿真驱动选择及 SA；不能将此曲线标为 Fig. 7-like LNA 曲线。
