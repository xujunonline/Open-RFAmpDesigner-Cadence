# 项目迁移历史

本目录保存项目从 Codex 对话任务迁移到独立工程时形成的历史资料。以下原始归档只保留在本机，并由 `.gitignore` 排除，避免把个人路径和完整聊天上下文发布到公开仓库：

- `Codex完整聊天记录_RFAmpDesigner.md`：迁移前可见聊天记录；
- `继续任务指南.md`：原任务恢复上下文时使用的说明；
- `legacy_workspace_README.md`：迁移资料包原始入口及完整任务提示词；
- `MANIFEST.tsv`：迁移时生成的原始文件清单。

这些文件用于追溯需求和决策，不是当前工程的操作入口。公开仓库只保留本说明和脱敏后的目录统一记录。当前入口是仓库根目录 `README.md` 和 `docs/00_index.md`。
