# 十月实验报告的证据复核

复核对象是 [139 号报告](139_experiment_report.md) 的表 20、资源比较、自进化实验及总结。以下勘误供十一月报告引用。十月的逐次通过与失败记录沿用原值。

| 原文位置及表述 | 原始记录支持的结论 |
|---|---|
| §6.8 表 20 与总结称锚点切换后“没有改变任何设计的结论” | 按实现、规格与 seed 去重，5 个设计中有 4 个保持原判。v2 S5 seed 1 原来通过，改用 Spectre 锚点后的两次运行均失败，分别受增益与 S11 限制。没有观察到失败转通过。两次搜索路径不同，无法仅据此把变化归因于锚点。 |
| §9.1 将 S3 失败归为 50 GHz 下“器件受限” | 十月 N65 S3 在所试条件下未找到通过方案。十一月调整首级几何与匹配，在原偏置网格内取得中心 NF 4.9193 dB，通过六项。十月样本可以定位噪声瓶颈，不能给出工艺可行性的下界。 |
| 将 N65 S9/S10 合计调用减少概括成通用效率提升 | 同取 seed 0–4，S9 的 v1、v2 都是 4/5，Spectre 调用为 101、113。S10 两者都是 0/5，调用为 300、28。合计 401 对 141，降幅主要来自仍未通过的 S10。 |
| 将缩放难例的 6/10 或自进化的 9.0 倍直接归功于记忆 | 6/10 对 0/10 来自代理后端的 S9s/S10s，且两套实现同时更换决策策略。9.0 来自 GA 与带记忆 v2 的平均等效秒数 11620/1292，成功数分别为 14/18 与 18/18。两项比较均缺少只改变记忆的配对对照。 |
| 把十一月“八项都有通过设计”写成十月 pass@1 的提升 | 十月 N65 固定试验中 v1 为 24/40，v2 为 21/40。十一月按案例续调并挑选通过设计，S7 还扩展了偏置网格。两组统计的起点、搜索范围和分母不同。 |
