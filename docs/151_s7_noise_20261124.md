1. 重建历史 S7 的第 3 条记录并复测，重现原指标。30 GHz 的噪声贡献按输出噪声功率归组，扣除两端口后输入管 M1 占 40.1%，共栅管 MCG 占 32.1%。先改首级的指宽、每组指数和并联数。固定匹配时，NF 曾降到 3.1464 dB，纹波却升至 3.8550 dB。

4. 比较频带两端与中心的 NF；从已测两端口结果移除输入电感的作用，在本机筛选更合适的输入匹配，再提交完整电路。只看中心会选到 2.43 dB 左右的方案。以全带最差值优先时，选中方案的中心值为 2.4743 dB，频带最差值为 2.6113 dB。
