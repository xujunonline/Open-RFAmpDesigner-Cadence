# Stage 06：公开 MOS1 多宽度教学表征

此项是**直接 Cadence Spectre + 公开教学 MOS1** 的方法链验证，不是授权 PDK 器件表，也不是论文三级 LNA sizing。`run_teaching_lna.py` 现仅允许 `WMOS=100..500 um`，长度仍固定 `100 nm`；偏置、输入/输出理想元件及模型按白名单保持不变。参数写入前验证固定公开模板和宿主物理内存门禁。旧 300 um 默认渲染及归档没有被覆盖。
